## ✨ Features

- **Modern Design**: Clean, professional layout with dark/light theme support
- **Full Responsiveness**: Optimized for all devices (mobile, tablet, desktop)
- **Smooth Animations**: AOS library integration for scroll-triggered animations
- **Typewriter Effect**: Dynamic text animation in hero section
- **Interactive Forms**: Contact form with real-time validation
- **Progress Animations**: Animated skill progress bars
- **SEO Optimized**: Proper meta tags, structured data, and semantic HTML
- **Accessibility**: WCAG AA compliant with keyboard navigation support
- **Fast Performance**: Optimized assets and lazy loading
- **Cross-browser Compatibility**: Tested on modern browsers

## 🛠 Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Framework**: Bootstrap 5.3
- **Icons**: Font Awesome 6
- **Fonts**: Google Fonts (Inter)
- **Animations**: AOS (Animate On Scroll)
- **Deployment**: GitHub Pages
